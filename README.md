В рамках данной работы был реализован алгоритм Дейкстры на языке Python для поиска кратчайших путей в взвешенном графе. Граф представлен в виде списка смежности, содержащего информацию о вершинах и весах рёбер между ними. Разработанная программа позволяет задавать произвольную начальную вершину и вычислять минимальные расстояния до всех остальных вершин графа. Для повышения эффективности работы алгоритма использована приоритетная очередь. В результате выполнения программы выводятся длины кратчайших путей, а также может быть восстановлен маршрут от начальной вершины до любой выбранной вершины графа.
